| Команда                                  | Описание                                               |
| ---------------------------------------- | ------------------------------------------------------ |
| `git init`                               | Инициализация нового локального репозитория            |
| `git clone <url>`                        | Клонирование удалённого репозитория                    |
| `git status`                             | Показать текущий статус файлов                         |
| `git add <файл>` / `git add .`           | Добавить файл или все изменения в индекс (staging)     |
| `git commit -m "сообщение"`              | Создать коммит с сообщением                            |
| `git log`                                | Показать историю коммитов                              |
| `git branch`                             | Показать список локальных веток                        |
| `git checkout <ветка>`                   | Переключиться на указанную ветку                       |
| `git checkout -b <ветка>`                | Создать новую ветку и сразу на неё переключиться       |
| `git merge <ветка>`                      | Слить указанную ветку с текущей                        |
| `git push origin <ветка>`                | Отправить локальные изменения на удалённый репозиторий |
| `git pull`                               | Получить изменения с удалённого репозитория и слить    |
| `git branch -d <ветка>`                  | Удалить локальную ветку                                |
| `git push origin --delete <ветка>`       | Удалить удалённую ветку                                |
| `git remote -v`                          | Показать удалённые репозитории                         |
| `git config --global user.name "Имя"`    | Установить имя пользователя для коммитов               |
| `git config --global user.email "email"` | Установить email для коммитов                          |
